# Blinkin' Park — Database Design & SQL

## Overview

Blinkin' Park is a university project developed as part of the Database Systems Laboratory during the 2025/2026 academic year.

The project focuses on designing a relational database, from conceptual modeling to logical design and SQL implementation.

## Project Objectives

- Apply database design principles to a practical case study.
- Develop a conceptual data model.
- Translate the conceptual model into a relational database schema.
- Implement the database using SQL.

## Project Workflow

**1. Conceptual Design**

Model the information and relationships required by the case study.

**2. Logical Design**

Translate the conceptual model into a relational schema.

**3. SQL Implementation**

Implement the relational database structure using SQL.
